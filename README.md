# Aditya Yadav — Advanced Portfolio

A dependency-free portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure/content
- `style.css` — complete responsive UI and light/dark themes
- `script.js` — interactions, project filters, case-study modal, theme toggle, animations
- `profile.jpg` — portfolio profile photo
- `favicon.svg` — AY favicon

## Run locally
Open `index.html` directly, or use VS Code Live Server.

## Deploy
Upload all files together to the same public directory on your hosting. Keep `profile.jpg`, `style.css` and `script.js` next to `index.html`.

## Easy edits
- Project content: search `projectData` in `script.js` and project cards in `index.html`.
- Colors: edit CSS variables at the top of `style.css`.
- Contact/social links: search your email/GitHub/LinkedIn in `index.html`.

Note: Google Fonts and Font Awesome icons are loaded from CDN, so an internet connection is needed for those external assets.
